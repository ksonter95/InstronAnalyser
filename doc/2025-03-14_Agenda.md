## Microindentation

**E-modulus**
- F = 4/3 * (E*) * R^0.5 * (h - a)^1.5 + b
    - E*: reduced modulus
    - 1 / E* = (1 - v^2) / E + (1 - vi^2) / Ei
    - If indenter properties are not considered, Ei = vi = 1 giving
      (1 - vi^2) / Ei = 0
- Calculated using Python's scipy.optimize.curve_fit() function for all data
  points in the specified compression cycle that have tip displacement / R less
  than the specified ratio, with initial guesses (E* = 1, a = minimum tip
  displacement, b = minimum force), and with parameter bounds (0 <= E < inf,
  -inf < a <= minimum tip displacement, -inf < b <= minimum force)
    - NOTE: the ratio limit is imposed on the tip displacement NOT the
      indentation depth
    - Very susceptible to initial guesses
    - What should happen if the function fails to converge to a solution?
      Currently, E = a = b = NaN
    - In the event that regression offsets are not used, a = minimum tip
      indentation, and b = force at minimum tip indentation
