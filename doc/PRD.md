# **Project Requirements Document: MechAnalyser 2.0.0**

The following table outlines the detailed functional and non-functional requirements of the MechAnalyser application for version 2.0.0.

| Requirement ID | Description               | User Story                                                                                       | Expected Behavior/Outcome                                                                                                     |
|-----------------|---------------------------|--------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| FR-001          | Configuring Experiments   | As a user, I want to configure experiment parameters so I can tailor the analysis to my needs.  | The system should provide a clear interface for selecting experiment types and setting parameters like strain range and cycles.                                    |
| FR-002          | Uploading Data Files      | As a user, I want to upload CSV files containing raw data so I can analyze them.                | The system should allow users to upload CSV files and validate their format before analysis.                                                                       |
| FR-003          | Analyzing Data            | As a user, I want to process raw data to calculate parameters like Young's modulus.             | The system should analyze the uploaded data and calculate key parameters, providing progress updates during the process.                                           |
| FR-004          | Visualizing Results       | As a user, I want to view plots of raw and processed data so I can understand the analysis.     | The system should generate and display interactive plots for both raw and processed data.                                                                          |
| FR-005          | Generating Reports        | As a user, I want to generate Excel reports containing analysis results so I can share them.    | The system should create Excel files with raw data, processed data, and summaries, saving them to a user-specified directory.                                      |
| FR-006          | Managing Output Files     | As a user, I want to edit output filenames and directories so I can organize my results.        | The system should provide options to rename output files and specify directories for saving them.                                                                  |
| FR-007          | Collating Data            | As a user, I want to collate data from multiple experiments into a single report.               | The system should combine data from multiple files into a single Excel report, grouped by sample or experiment type.                                               |
| FR-008          | Canceling Analysis        | As a user, I want to cancel an ongoing analysis if needed.                                      | The system should allow users to stop the analysis process at any time and provide feedback on the cancellation.                                                   |
| FR-009          | Viewing Analysis Progress | As a user, I want to see the progress of the analysis so I know how long it will take.          | The system should display a progress bar or status updates during the analysis process.                                                                            |
| FR-010          | Saving and Reopening Sessions | As a user, I want to save my session and reopen it later to continue viewing plots or analyzing data. | The system should allow users to save their current session, including all configurations, plots, and analysis, and reopen it at a later time.                     |
| FR-011          | Configuring Multiple Experiments | As a user, I want to configure and analyze multiple experiments within the same application.    | The system should allow users to configure and analyze multiple experiments simultaneously, grouping them into a single study.                                      |
| FR-012          | Grouping Experiments into Studies | As a user, I want to group multiple experiments into a study for better organization.           | The system should provide functionality to group experiments into a study and manage them collectively.                                                            |
| FR-013          | Plotting Summary Results  | As a user, I want to plot summary results to visualize key findings.                           | The system should generate plots for summary results, in addition to raw and processed data.                                                                       |
| FR-014          | Plotting Grouped Data     | As a user, I want to plot raw and processed data of samples belonging to the same group on the same plot. | The system should allow users to overlay data from grouped samples on a single plot for comparison.                                                                |
| FR-015          | Configuring Plot Data     | As a user, I want to configure what data is plotted where for better customization.             | The system should provide options to configure which data is plotted and how it is displayed.                                                                      |
| FR-016          | Customizing Plot Appearance | As a user, I want to configure the appearance of plots to suit my preferences.                 | The system should allow users to customize plot appearance, including colors, labels, and styles.                                                                 |
| FR-017          | Choosing Plot Types       | As a user, I want to choose different types of plots (e.g., scatter, column, box, pie).         | The system should support multiple plot types and allow users to select the most appropriate one for their data.                                                   |
| FR-018          | Conducting Statistical Analysis | As a user, I want to perform statistical analysis on summary results to determine significance. | The system should provide tools for statistical analysis and generate results indicating statistical significance.                                                  |
| FR-019          | Grouping Studies into Laboratories | As a user, I want to group multiple studies into a laboratory for better organization.          | The system should allow users to group studies into a laboratory and manage them collectively.                                                                     |
| FR-020          | Defining Sample Properties | As a user, I want each sample to have properties like region, specimen, and group for better categorization. | The system should support defining and managing sample properties, including region, specimen, and group, for better data organization and analysis.                |
| FR-021          | Bidirectional Queries for Samples | As a user, I want to query samples by laboratory, study, experiment, group, specimen, or region. | The system should allow bidirectional database-style queries to retrieve samples based on their associations.                                                      |
| FR-022          | Bidirectional Queries for Associations | As a user, I want to query laboratories, studies, and experiments by sample group, specimen, or region. | The system should allow bidirectional database-style queries to retrieve associations based on sample properties.                                                  |
| FR-023          | Generating PDF Documentation | As a user, I want to generate PDF reports of analysis results with tables, plots, and statistical significance. | The system should generate well-formatted PDF documents containing analysis results, including tables, plots, and statistical significance.                        |
| FR-024          | GUI Layout Customization | As a developer, I want to use PySide6 and pyside6-designer to customize the GUI layout.         | The system should use PySide6 for the GUI and support layout customization via pyside6-designer.                                                                   |
| FR-025          | Help Section              | As a user, I want a searchable help section to find answers to my questions.                   | The system should include a help section with keyword-based search functionality.                                                                                  |
| FR-026          | Documentation Section     | As a user, I want a searchable documentation section outlining instruments, experiments, data input/output, and purposes. | The system should include a documentation section with keyword-based search functionality for detailed experiment and instrument information.                      |
| FR-027          | Exporting Data to JSON     | As a user, I want to export analysis results to JSON format for integration with other tools. | The system should allow exporting processed data and summaries to JSON files, maintaining compatibility with external applications. |
| FR-028          | Importing Data from JSON   | As a user, I want to import JSON files containing experiment configurations and data.         | The system should support importing JSON files to restore configurations and data for analysis. |
| NFR-001         | Supporting Multiple Platforms | As a user, I want the application to work on my prefered operating system, be it macOS or Windows.      | The system should be compatible with macOS and Windows and provide a seamless installation and usage experience.                                                              |
| NFR-002         | Handling Large Datasets   | As a user, I want the application to handle large datasets efficiently so I can analyze complex experiments. | The system should process large datasets without significant performance degradation, ensuring accurate and timely results.                                         |
| NFR-003         | Error Handling            | As a user, I want the application to handle errors gracefully so I can troubleshoot issues.     | The system should provide clear error messages and logs for issues like invalid file formats or missing data.                                                      |
| NFR-004         | Extensibility for New Modules | As a developer, I want to add new experiments or instruments by implementing a module and registering it in one location. | The system should allow developers to extend functionality by creating a new module and registering it in a single, centralized location without requiring changes across multiple files. |
